# `ultralytics` is AGPL-3.0. SensorDyme both conveys the software on hardware and

# See docs/LICENSING.md for the full analysis.
#
# So the split is by DESTINATION, not by role: everything here reaches customer
# hardware; requirements.txt adds what only a developer machine and CI need.
# Nothing AGPL- or GPL-licensed may be added to this file without a licence
# review. tests/test_phase4_no_agpl_runtime.py enforces the ultralytics/torch
# exclusion mechanically.
#
# The device detects on the AI HAT+ (core/accel.py's HailoYOLO, which does its
# own letterboxing, DFL decode and NMS against a compiled .hef and needs no
# inference framework). With no accelerator AND no ultralytics there is no
# detector at all, and core.detectors.get_yolo_model raises a message saying so
# rather than degrading silently.
