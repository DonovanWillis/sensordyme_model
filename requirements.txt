# SensorDyme DEVELOPER + CI runtime dependencies.
#
# This is the Mac dev install (setup_mac.sh) and what CI installs. It is NOT what
# ships: `requirements-device.txt` is the set that reaches customer hardware, and
# it is included below so the shared pins live in exactly one place. Two
# hand-maintained copies of the same packages drift, and the way that shows up is
# a device running a different opencv than CI tested against.
#
#   device  →  requirements-device.txt        (setup_pi.sh, make deploy)
#   dev/CI  →  requirements.txt               (setup_mac.sh, CI) — this file
#   tooling →  requirements-dev.txt           (ruff, pyright, pytest-cov, ...)
#
# Python 3.11+ required (mediapipe does not yet support 3.13+).
-r requirements-device.txt

# --- Developer machines and CI ONLY. NOT installed on a device. --------------
# ultralytics is AGPL-3.0 (confirmed in the installed dist-info METADATA), and
# SensorDyme both conveys software on hardware and serves inference over a
# network from it — so putting this on a shipped device triggers AGPL §13 and the
# §4/§6 conveying obligations. See docs/LICENSING.md.
#
# It stays here because it is legitimately useful OFF the device, where nothing
# is conveyed to anyone:
#   * the mac_max profile (modules/driver_attention_max.py) detects on MPS,
#   * benchmarks/accuracy_state_farm.py measures the CPU baseline the Hailo
#     accuracy numbers are compared against,
#   * scripts/prepare_state_farm.py produces an ultralytics-native training
#     layout, and training happens on a workstation.
#
# It also pulls torch + torchvision (~800MB), which is a second, independent
# reason not to put it on a Pi.
#
# Removing this line is NOT the remaining licence work — the device install no
# longer references it. Keeping it is what preserves the dev path.
ultralytics==8.3.28

# Imported directly by modules/driver_attention_max.py (require_mps), so pinned
# here rather than left to whatever ultralytics happens to resolve. Same
# developer-only status as ultralytics: never on a device.
torch==2.14.1
